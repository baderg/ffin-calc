Калькулятор ПА Freedom Life — выкладка на GitHub Pages
1. Создайте новый репозиторий (например ffin-calc), загрузите в корень все файлы из этой папки:
   index.html, users.json, sw.js, manifest.webmanifest, icon-192.png, icon-512.png
2. Settings -> Pages -> Deploy from branch -> main / root.
3. Откройте ссылку на телефоне -> меню браузера -> «Установить приложение / Добавить на главный экран».
Пользователи: вкладка «Админ» (после входа администратором). После добавления/удаления нажмите
«Скачать users.json» и загрузите файл в репозиторий вместо старого.
Ежегодно обновляйте прожиточный минимум (ПМ) в engine.js (P.PM) и пересобирайте (node build.js).
